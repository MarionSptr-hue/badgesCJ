# Badges — Concrete Jungle

Ce dépôt contient les badges de profil de Concrete Jungle.

Les fichiers publics sont rangés dans `badges/` par catégorie. Une fois GitHub Pages activé, une image sera accessible avec une URL, ne pas renommer ni déplacer un fichier après son intégration au JavaScript Forumactif : son URL publique serait cassée.

Inventaire actuel : 128 images.
